# 🚀 Quick Deployment Guide

## Hızlı Başlangıç (3 Seçenek)

### Option 1: VPS (Önerilen - $5/ay) ⭐⭐⭐⭐⭐

**En iyi performans, tam kontrol**

```bash
# 1. VPS Satın Al (Hetzner veya DigitalOcean)
# 2. SSH ile bağlan
ssh root@your-vps-ip

# 3. Kurulum scripti çalıştır
curl -o setup.sh https://your-repo/scripts/vps-setup.sh
chmod +x setup.sh
./setup.sh
```

**Adımlar:**
1. Domain'i VPS IP'sine yönlendir (A record)
2. SSL sertifikası otomatik kurulacak
3. 10 dakikada hazır!

**Maliyet:** $5-6/ay
**Zorluk:** ⭐⭐⭐

---

### Option 2: Railway (En Kolay - Ücretsiz/ay) ⭐⭐⭐⭐⭐

**Zero-config, otomatik deployment**

#### Backend:
1. https://railway.app → GitHub ile giriş
2. "New Project" → "Deploy from GitHub"
3. Backend repo seçin
4. Environment Variables ekleyin:
   ```
   MYSQL_HOST=<railway-mysql-host>
   MYSQL_USER=root
   MYSQL_PASSWORD=<auto-generated>
   MYSQL_DB=railway
   JWT_SECRET_KEY=<generate-random>
   ```
5. MySQL plugin ekleyin (Project → New → Database → MySQL)
6. Deploy! 🚀

Backend URL: `https://your-app.up.railway.app`

#### Frontend (Vercel):
1. https://vercel.com → GitHub ile giriş
2. "Import Project"
3. Frontend repo seçin
4. Environment Variable:
   ```
   REACT_APP_BACKEND_URL=https://your-backend.up.railway.app
   ```
5. Deploy! 🚀

**Maliyet:** Ücretsiz (500 saat/ay) → $5/ay
**Zorluk:** ⭐

---

### Option 3: PythonAnywhere ($5/ay) ⭐⭐⭐⭐

**Python-friendly hosting, kolay yönetim**

1. https://www.pythonanywhere.com → Sign up
2. Console'dan:
   ```bash
   git clone your-repo-url yzr-backend
   cd yzr-backend
   mkvirtualenv --python=/usr/bin/python3.10 yzr-env
   pip install -r requirements.txt
   ```
3. Web → "Add a new web app"
   - Manual configuration
   - Python 3.10
   - WSGI file düzenle (guide'da detay var)
4. MySQL → "Initialize MySQL"
5. Environment variables ayarla
6. Reload web app

**Maliyet:** $5/ay
**Zorluk:** ⭐⭐

## cPanel (Shared Hosting) - ⚠️ Sınırlı Destek

**Uyarı:** Çoğu shared hosting FastAPI'yi çalıştıramaz!

**Ön Gereksinimler:**
- Python 3.9+ desteği
- SSH erişimi
- MySQL database

**Adımlar:**
1. cPanel → "Setup Python App"
2. Python version: 3.9+
3. App root: `/home/username/backend`
4. Startup file: `passenger_wsgi.py`
5. `requirements.txt` install
6. MySQL database oluştur
7. `.env` dosyası ayarla
8. Restart app

⚠️ **Sorun yaşarsanız VPS kullanın!**

## Hızlı Komutlar

### Backend Build & Deploy
```bash
cd backend
pip install -r requirements.txt
python migrate_to_mysql.py  # First time only
uvicorn server:app --host 0.0.0.0 --port 8001
```

### Frontend Build
```bash
cd frontend
npm install
npm run build
# Build output: /frontend/build/
```

### MySQL Backup
```bash
mysqldump -u user -p yzr_yangin > backup.sql
```

### Restore
```bash
mysql -u user -p yzr_yangin < backup.sql
```

## Hızlı Domain Setup

### Railway Backend
1. Railway dashboard → Settings → Domains
2. "Generate Domain" veya custom domain ekle
3. DNS: CNAME → `your-app.up.railway.app`

### Vercel Frontend
1. Vercel dashboard → Domains
2. Custom domain ekle
3. DNS: A record veya CNAME (Vercel'in yönlendirmesi)

### Tek Domain Altında (opsiyonel)
```
yourdomain.com → Frontend (Vercel)
yourdomain.com/api → Backend (Railway - proxy)
```

Vercel `vercel.json`:
```json
{
  "rewrites": [
    {
      "source": "/api/:path*",
      "destination": "https://your-backend.up.railway.app/api/:path*"
    }
  ]
}
```
